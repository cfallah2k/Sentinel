# SENTINEL MVP product brief

## Product goal

Sentinel is an AI data governance and control platform designed to help organizations understand where data goes, what AI systems touch it, and what policies govern exposure.

## MVP scope

- marketing and conversion site
- secure email/password auth shell
- organization onboarding flow
- policy and classification engine foundation
- gateway simulation for allow/block/redact decisions
- dashboard and data-flow views
- audit and incident-ready event reporting
- Docker-based deployment model

## Proof points

- National ID to external provider is blocked.
- Phone number is redacted before external AI transmission.
- Approved provider email flows are allowed.
- Dashboard updates and audit events record each decision.

## Phase 1 milestone

The first milestone establishes the repository, scaffolding, and security-first architecture foundation. This is the basis for the complete governance product that will be extended in later milestones.
